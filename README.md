# HeadshotMod

A mod for **Terraria (tModLoader)** developed in C# that adds critical headshot mechanics, increasing the accuracy and tactical impact of combat.

---

## 🎯 About the Mod
The **HeadshotMod** was created to reward players' aim, introducing dynamic damage bonuses when projectiles hit the upper part of enemies.

---

## 🚀 Features
* **Headshot System:** Critical hit detection based on target position.

* **Compatibility:** Developed to work natively with tModLoader.

* **Open Source:** Feel free to explore the source code, suggest improvements, or report problems.

---

## 🛠️ Technologies Used
* **Language:** C# (.NET)
* **Platform:** tModLoader (Terraria Modding API)

---

## 📌 Status
Under continuous development for balance improvements and new mechanics.
