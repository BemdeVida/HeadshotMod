# HeadshotMod

Um mod para **Terraria (tModLoader)** desenvolvido em C# que adiciona mecânicas de acertos críticos na cabeça (*headshots*), aumentando a precisão e o impacto tático dos combates.

---

## 🎯 Sobre o Mod
O **HeadshotMod** foi criado para recompensar a mira dos jogadores, introduzindo bônus de dano dinâmicos quando projéteis acertam a parte superior dos inimigos.

---

## 🚀 Funcionalidades
* **Sistema de Headshot:** Detecção de acertos críticos baseada na posição do alvo.
* **Compatibilidade:** Desenvolvido para funcionar nativamente no tModLoader.
* **Código Aberto:** Sinta-se à vontade para explorar o código-fonte, sugerir melhorias ou relatar problemas.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C# (.NET)
* **Plataforma:** tModLoader (Terraria Modding API)
